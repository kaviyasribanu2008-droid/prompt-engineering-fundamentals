## Prompt Engineering

**Basic Prompt:** Explain cloud computing.  
**Output:** Accessing servers, storage, and apps over the internet on demand.

**Improved Prompt:** Explain cloud computing to a student in 2 bullet points with an example.  
**Output:**  
- Use storage and software online without buying hardware.  
- Example: Saving files on Google Drive.

**What Changed:** Added audience (*student*), limit (*2 bullet points*), and an *example* for a clearer, shorter answer.
